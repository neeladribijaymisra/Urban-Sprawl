# 🚀 UrbanScope AI SaaS

### AI-Powered Urban Sprawl Detection & Geospatial Intelligence Platform

UrbanScope AI SaaS is a scalable and enterprise-ready geospatial intelligence platform built for urban sprawl detection, land-cover classification, and satellite imagery analytics using AI and deep learning.

The platform combines a modern React frontend, ASP.NET Core backend services, and machine learning workflows to deliver intelligent urban monitoring, spatial analytics, and environmental change detection.

---

## 📌 Overview

UrbanScope centralizes satellite image analysis and urban monitoring workflows into a unified SaaS ecosystem, enabling organizations and researchers to analyze land-cover changes, monitor urban growth, and visualize geospatial insights through interactive dashboards and AI-powered prediction systems.

Built with scalability and modularity in mind, the platform supports multi-tenant architecture, secure authentication, and high-performance REST APIs for modern geospatial applications.

# 📊 Urban Sprawl Scoring Logic

UrbanScope calculates an urban sprawl score using probabilities from urban-related land-cover classes.

### 🏙️ Urban Classes
- Residential
- Industrial
- Highway

### 🌱 Green Classes
- Forest
- HerbaceousVegetation
- Pasture
- AnnualCrop
- PermanentCrop

### 🌊 Water Classes
- River
- SeaLake

### 📌 Sprawl Formula

```text
Residential + Industrial + Highway probabilities
```
